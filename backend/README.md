# LMS Backend

This is the backend of the LMS Project built with Node.js, Express, and MongoDB.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables (create a `.env` file).

3. Run the development server:
   ```bash
   npm run dev
   ```

## Scripts
- `npm run dev`: Starts the server with nodemon for development.
- `npm start`: Starts the server normally.
- `npm run seed`: Seeds the database (if needed).

## Technologies Used
- Node.js
- Express
- Mongoose
- JSONWebToken
- Bcryptjs
