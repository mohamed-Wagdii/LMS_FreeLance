# LMS Frontend

This is the frontend of the LMS Project built with Vue 3, Vite, and Frappe UI.

## Setup Instructions

1. Install dependencies:
   ```bash
   yarn install
   ```

2. Run the development server:
   ```bash
   yarn dev
   ```

3. Build for production:
   ```bash
   yarn build
   ```

## Technologies Used
- Vue 3
- Vite
- TailwindCSS
- Frappe UI
- Pinia (State Management)
- Vue Router
